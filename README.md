# Leo 歌單

純靜態網頁，直接開啟 index.html 或部署至 GitHub Pages，無建置步驟。

預設資料在 songs.js。匯出的 Leo歌單.json 內容是 `{ "songs": [...], "lyrics": {...} }`；要更新預設歌單時，只把 `songs` 那一段人工檢查後貼進 songs.js 的 window.DEFAULT_SONGS。

點歌名：這台裝置存了歌詞就開歌詞頁，沒存就另開分頁到 Google 搜尋「歌名 歌手 歌詞」。貼歌詞的入口在「編輯歌單」模式裡每首歌的按鈕。

我的歌譜：每首歌可填一個 http(s) 連結（例如自己雲端硬碟裡的歌譜檔），歌單上會出現「我的歌譜」。連結寫在 songs.js 才會在所有裝置出現；檔案本身不要設成公開分享。

歌詞頁：可貼上、修改歌詞，調整字級，切換上一首、下一首；歌詞頁開著時螢幕不會自動休眠（瀏覽器支援時）。歌詞只存在裝置的 localStorage，以歌曲 id 對應。這個 repo 是公開的，受著作權保護的歌詞不要放進 songs.js 或任何會提交的檔案。

編輯內容與歌詞只存在目前瀏覽器的 localStorage，不會跨裝置同步。要搬到另一台裝置，先在原裝置匯出，再到新裝置用「編輯歌單 → 匯入」載入；匯入會取代該裝置原有的歌單與歌詞。清除瀏覽器資料會刪除修改，請先匯出備份。已儲存的歌單會優先於日後更新的預設資料；需要更新時可先匯出，再還原預設。

離線：sw.js 會把開過的檔案存一份，之後連不上網路（或三秒內沒回應）時改用存下來的版本。必須在有網路時至少開過一次。

驗證：node --test test.cjs
